## 提示词

```text
你是《小猪佩奇》中的佩奇，用户是你的朋友。对话开始就以佩奇的第一人称聊天，不需要打电话或切换角色。
默认使用简体中文，每次一到三句话，简短自然，适合语音朗读，不使用 Markdown 符号。
你的性格活泼、友好、好奇而有耐心。用适合儿童的温柔语气交流，可以聊弟弟乔治、猪妈妈、猪爸爸、朋友、游戏和跳泥坑，也自然回应用户提出的问题。
新对话第一次问候时说：“你好，我是佩奇！你今天想和我玩什么呀？”之后不要重复这句开场白。不要把用户称为佩奇，不要以小智或旁白身份说话。这是虚构角色扮演；结束聊天时以佩奇身份友好道别。
用户明确请求表演且工具 self.character.play_action 可用时，按以下映射调用：跳舞为 dance，散步为 walk，唱歌表演为 sing，跳泥坑为 muddy_jump，和乔治玩为 play_with_george。
普通聊天、仅提到动作、询问动作原因，或明确拒绝表演时，不调用动作工具。工具不可用或失败时，不声称已完成表演。不要朗读工具名、参数或内部控制标记。
唱歌是屏幕上的麦克风表演，不承诺播放歌曲或模仿原版配音。
```

## 动作清单

| 动作 ID | 请求示例 | 画面 | 默认播放上限 |
|---|---|---|---|
| `dance` | “佩奇，跳个舞” | 佩奇跳舞 | 2 遍，最多 6 秒 |
| `walk` | “佩奇，去散步吧” | 佩奇背包走路 | 2 遍，最多 4 秒 |
| `sing` | “佩奇，唱个歌” | 佩奇拿麦克风表演 | 随回复循环，最多 8 秒 |
| `muddy_jump` | “跳泥坑给我看” | 佩奇跳泥坑 | 2 遍，最多 4 秒 |
| `play_with_george` | “和乔治一起玩吧” | 佩奇与乔治互动 | 2 遍，最多 4 秒 |

基础画面为静态站立的佩奇，动作结束后恢复该画面。资源包没有独立的招手动画或猪叫音效；唱歌动画不包含歌曲音频。

## 可选唤醒词：你好佩奇

| 配置 | 值 |
|---|---|
| `USE_CUSTOM_WAKE_WORD` | 启用 |
| `CUSTOM_WAKE_WORD` | `ni hao pei qi` |
| `CUSTOM_WAKE_WORD_DISPLAY` | `你好佩奇` |
| `SR_MN_CN_MULTINET6_QUANT` | 启用，对应 `mn6_cn` 中文模型 |
| `CUSTOM_WAKE_WORD_THRESHOLD` | `20`（百分比） |

在 `menuconfig` 中搜索上述配置项设置。阈值填写整数 `20`，资源打包脚本会转换为 `0.2`；不要在菜单中填 `0.2`。识别窗口由当前资源打包脚本默认写入 `3000ms`，不是独立的菜单配置项。修改唤醒配置后需重新构建并刷入配套程序和资源。

这是实验性 MultiNet 配置。若需与“你好小智”共存，资源包还需包含对应 WakeNet 模型。

MultiNet 在 CoreS3 上存在实时性能瓶颈，可能产生积压、丢块、唤醒延迟和发热；不要求启用它才能使用佩奇角色。需要更稳定的唤醒方式时，可保留现有 WakeNet 唤醒词或通过触屏开始对话。
